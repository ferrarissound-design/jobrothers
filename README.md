# ジョーブラ (JOE BROS) — v1.0

ブラウザで遊べる、オリジナル3D対戦アクションゲームです。

「どこかで見たことがあるような雰囲気を持ちながら、名称・衣装・体型・技・設定はすべて独自」
をコンセプトに、4人のファイターが破壊可能な3Dアリーナで吹き飛ばし合います。

キャラクターの3Dモデルは外部モデルを使わず、Three.js の基本図形
（Box / Sphere / Cylinder / Cone / Capsule）を組み合わせて生成しています。
効果音は Web Audio API による生成音、BGM は `public/bgm/` の自作AI生成楽曲です。

## 現在の完成ライン

v1.0では、1人用の対CPUアリーナゲームとして一通りのゲームループを完成扱いにしています。

- 起動時のキャラクター選択
- プレイヤー1人 vs CPU3人
- ダメージ%式の吹き飛ばしバトル
- 3ストック / 3分制
- 地上攻撃・空中攻撃・急降下スパイク
- 二段ジャンプ・空中回避・崖つかまり
- ガード / ガードブレイク / ダッシュ
- キャラクター固有必殺技
- 5種類のアイテム
- 破壊可能オブジェクト・爆発物
- CPU難易度 Easy / Normal / Hard
- PC / スマートフォン操作
- キャラクター選び直し / 再戦 / リザルト順位
- BGM・効果音・画質・アイテム頻度設定の保存
- PR時の自動テスト＋本番ビルド検証

## 起動方法

```bash
npm install
npm run dev       # 開発サーバー起動（http://localhost:5173）
npm test          # 単体テスト
npm run typecheck # 型チェック
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果のプレビュー
```

バックエンドは不要です。`npm run build` 後の `dist/` を静的ホスティングすれば動作します。

## GitHub Pages

`.github/workflows/deploy.yml` により、`main` へのプッシュでテスト・ビルド・GitHub Pages公開が
自動実行されます。

初回のみ GitHub の **Settings → Pages → Build and deployment → Source** を
**GitHub Actions** に設定してください。

> リポジトリ直下をそのまま静的配信すると動きません。`src/main.ts` はTypeScriptなので、
> 必ずViteでビルドした `dist/` を公開します。

Pull Requestでは `.github/workflows/ci.yml` が `npm test` と `npm run build` を実行し、
壊れた変更を `main` に入れる前に検出します。

## キャラクター選択

ゲーム起動時に4人から1人を選び、残り3人がCPUとして参戦します。

- 選択中キャラクターの3Dプレビューを表示
- スピード / パワー / ふっとばし / ジャンプ / 防御 / 重さ / 必殺技を比較表示
- `←` `→` または `A` `D` で選択、`Enter` / `Space` で決定
- タッチ・マウスではカードを選択して決定
- 最後に選んだキャラクターを保存
- ポーズ画面・リザルト画面から選び直し可能

## 操作方法

### PC

| キー | 動作 |
| --- | --- |
| W / A / S / D | 移動 |
| マウス移動 | カメラ視点操作（キャンバスをクリックしてポインターロック） |
| 左クリック | 通常攻撃 / 空中攻撃 / 所持アイテム使用 |
| 右クリック | 強攻撃 / 空中では急降下スパイク |
| E | 必殺技 |
| Q（長押し） | ガード |
| Shift（長押し） | ダッシュ |
| Ctrl または C | 回避 / 崖つかまり中は手を離す |
| Space | ジャンプ / 空中で二段ジャンプ / 崖つかまり中はよじ登る |
| R | カメラ位置リセット |
| Esc | ポーズ |
| F3 | デバッグ表示切替 |

操作キーは `src/config/controls.ts` に集約しています。

### スマートフォン / タッチ端末

- 左側: 仮想スティックで移動
- スティックを大きく倒すとダッシュ
- 右側: 攻撃 / 強攻撃 / 必殺技 / ジャンプ / ガード / 回避
- 空中の強攻撃はスパイク
- 画面ドラッグでカメラ操作
- 視点リセットボタンあり
- マルチタッチ対応
- safe-area と可視ビューポートに合わせて操作UIを配置

タッチ対応端末のうち、粗いポインタを持つ端末、または画面幅が狭い端末をモバイル操作として扱います。

## ゲームルール

- プレイヤー1人 vs CPU3人
- 攻撃を受けるほどダメージ%が増加
- %が高いほど強く吹き飛ぶ
- ステージ外へ落下すると1ストック失う
- 初期ストックは3
- プレイヤーの全ストック消失で即敗北
- 3分経過時は **残ストック数 → ダメージ%の少なさ** で順位決定

### 空中戦

地上と空中では攻撃が変化します。

- 空中通常攻撃: 発生が速い迎撃向け
- 空中強攻撃: 相手を下方向へ叩くキャラクター固有スパイク
- スパイクは自分と同じ高さか下の相手にのみ当たりやすい設計
- CPUも空中の位置関係を見て通常空中攻撃とスパイクを使い分けます

### 崖つかまり

落下中にステージ外周へ近づくと自動で崖につかまります。

- 二段ジャンプと空中回避が復活
- 短い無敵時間あり
- `Space` でよじ登る
- 回避ボタンで手を離す
- 一定時間で自動的に手を離す
- 再つかまりには短いクールダウンあり

### ガードと回避

- ガードには耐久値があり、削り切られるとガードブレイク
- ガード解除後は耐久値が徐々に回復
- 回避には短い無敵時間とクールダウン
- 空中回避は着地または崖つかまりまで1回
- CPUは攻撃予兆に反応し、回避かガードを選択
- CPUのガードは攻撃の有効時間を覆えるよう短時間保持

## キャラクター

| キャラクター | タイプ | 特徴 |
| --- | --- | --- |
| **ジョリオ** | 万能型 | 赤い作業着の下水道の王。扱いやすい近中距離型。必殺技「マンホールギザー」 |
| **ビリネズ** | 高速型 | 黄色い電気生物。速いが軽く吹き飛びやすい。必殺技「ジグザグスパーク」 |
| **ハヤスギ** | 突進型 | 高速移動スーツの戦士。最高速が高い上級者向け。必殺技「ハイパーダッシュモード」 |
| **ダンボール・ジョー** | 罠・遠距離型 | 段ボール装甲の潜入兵士。ロケット花火と地雷を使う遠距離型 |

キャラクター性能は `src/characters/characterData.ts`、攻撃性能は
`src/characters/attacks.ts` に分離しています。

## アイテム

試合中、ステージ上空からアイテムが落下します。触れるだけで取得できます。

| アイテム | 種類 | 効果 |
| --- | --- | --- |
| **デカスパナ** | 武器（5回） | 遅い代わりに高威力・高ふっとばしの近接攻撃 |
| **ドラム缶ボム** | 投擲（1回） | 放物線で投げ、着弾時に爆発。自爆あり |
| **ジャンクブラスター** | 射撃（6回） | 前方へ直進弾を発射 |
| **ジャンクバーガー** | 即時 | ダメージ%を回復 |
| **ゴールドギア** | 即時 | 一定時間、無敵＋移動速度上昇 |

- 所持は1個まで
- 通常攻撃ボタンで使用
- 強攻撃と必殺技は所持中も使用可能
- ストックを失うと所持アイテムも失う
- 出現頻度は **なし / 少なめ / ふつう / 多め** から変更可能
- CPUもアイテムを発見して取りに行き、射撃・投擲を使用

- コンテナ・鉄骨・ドラム缶・自動販売機・クレーン・パイプ

## CPU AI

CPUはキャラクターごとの性格と難易度をもとに意思決定します。

- ターゲット選択
- 接近 / 離脱 / 横移動
- ダッシュ
- 通常・強・必殺技
- 空中通常攻撃・スパイク
- ガード・回避
- 落下時の復帰
- 崖からの復帰
- 障害物回避
- アイテム探索・使用
- ステージ端での危険回避

難易度が上がるほど判断間隔・反応時間・ミス率・アイテム探索範囲が強化されます。

## 設定保存

以下はブラウザの `localStorage` に保存されます。

- 画質
- CPU難易度
- アイテム出現頻度
- 効果音量
- BGM音量
- 最後に選んだキャラクター

Safariのプライベート環境などで `localStorage` が使えない場合は、メモリ上の設定で継続します。
また、古いバージョンや手動編集による不正な画質・難易度・アイテム設定値は無視し、
安全な初期値へフォールバックします。

## パフォーマンス

画質は Low / Medium / High から選択できます。

- devicePixelRatio 上限
- 影の有無とシャドウマップ解像度
- パーティクル上限
- 破片上限
- 描画距離

スマートフォンは Medium が初期値です。

## デバッグ

`F3` でデバッグ表示を切り替えます。

- FPS
- シーン内オブジェクト数
- パーティクル数
- 地雷数
- アイテム数 / 投射物数 / 座標
- カメラ角度
- 各キャラクターの座標・速度・ダメージ%・状態・攻撃ID
- CPUの現在ターゲット

# ジョーブラ (JOE BROS) — MVP

ブラウザで動く、オリジナル3D対戦アクションゲームのMVP（プレイ可能な最小構成版）です。
「どこかで見たことがあるようなキャラクターたちが、破壊可能な3Dステージで吹き飛ばし合う」
ことをコンセプトに、衣装・名称・体型・技・設定はすべて独自のオリジナルとしています。

外部の著作権素材（画像・音源・3Dモデル）は一切使用していません。キャラクターは
Three.jsの基本図形（Box / Sphere / Cylinder / Cone）を組み合わせた自作ローポリモデル、
効果音はすべてWeb Audio APIによる生成音です。

## 起動方法

```bash
npm install
npm run dev       # 開発サーバー起動（http://localhost:5173）
npm run build     # 本番ビルド（dist/ に出力）
npm run preview   # ビルド結果のプレビュー
npm run typecheck # 型チェックのみ実行
```

外部サーバーやバックエンドは不要です。`npm run build` 後の `dist/` フォルダは
そのまま静的ホスティング（GitHub Pages等）に配置して動作します。

## 公開（デプロイ）方法

> **重要:** リポジトリ直下をそのまま静的配信しても動きません（画面が白くなります）。
> `index.html` が読み込む `src/main.ts` は **TypeScript** のため、ブラウザは実行できず、
> `.ts` は JavaScript ではない MIME type で配信されてモジュール読み込みが拒否されます。
> 必ず `npm run build` で生成した `dist/` を配信してください。

### GitHub Pages

`.github/workflows/deploy.yml` により、`main` へのプッシュで自動的にビルドと公開が行われます。
初回のみ、リポジトリ側で以下の設定が必要です。

1. GitHub の **Settings → Pages** を開く
2. **Build and deployment → Source** を **「GitHub Actions」** に変更する
   （「Deploy from a branch」のままだと、ビルドされていない生のソースが配信されて白画面になります）

設定後、`main` にプッシュするか **Actions → Deploy to GitHub Pages → Run workflow** を
実行すると公開されます。公開URLは Actions の実行結果に表示されます。

### その他の静的ホスティング

```bash
npm ci
npm run build     # dist/ が生成される
```

生成された `dist/` の中身をそのまま配信してください。`vite.config.ts` の `base: "./"` に
より資産パスは相対参照になっているため、サブディレクトリ配下でもそのまま動作します。

## 操作方法

### PC

| キー | 動作 |
| --- | --- |
| W / A / S / D | 移動 |
| マウス移動 | カメラ視点操作（キャンバスをクリックしてポインターロック） |
| 左クリック | 通常攻撃 |
| 右クリック | 強攻撃 |
| E | 必殺技 |
| Q（長押し） | ガード |
| Shift（長押し） | ダッシュ |
| Ctrl または C | 回避（無敵時間あり） |
| Space | ジャンプ（空中で1回だけ二段ジャンプ可） |
| R | カメラ位置リセット |
| Esc | ポーズ |
| F3 | デバッグ表示切替 |

操作キーは `src/config/controls.ts` にまとめてあり、変更が容易な構造になっています。

### スマートフォン

- 画面左側: 仮想スティックで移動（スティックを大きく倒すとダッシュ）
- 画面右側: 攻撃 / 強攻撃 / 必殺技 / ジャンプ / ガード / 回避 の6ボタン
- マルチタッチ対応（移動しながら攻撃・ジャンプ可能）
- 画面スクロールや長押しメニューが出ないように制御済み
- 画面サイズに応じてUIレイアウトが自動調整されます

タッチデバイス（`pointer: coarse` かつ画面幅900px未満）を自動検出してモバイル操作
UIを表示します。カメラは移動方向へ自動で追従します（マウス視点操作の代わり）。

## ゲームルール

- プレイヤー1人 vs CPU3人の3Dアリーナ対戦
- 攻撃を受けるとHPではなく**ダメージ%**が蓄積し、%が高いほど大きく吹き飛ぶ
- ステージ外へ落下、または一定の高さより下に落ちると1ストックを失う
- 初期ストックは3。最後までストックが残っていたキャラクターの勝利
- 制限時間（3分）到達時は、ストック数→ダメージ%の少なさで勝敗を判定
- 空中では二段ジャンプ・空中回避が1回ずつ使用可能（復帰用）
- ガードには耐久値があり、削り切られるとガードブレイクして一定時間行動不能に
- 回避には短い無敵時間とクールダウンがある

### 吹き飛ばし計算

```
吹き飛ばし力 = (攻撃の基礎吹き飛ばし力 + 吹き飛ばし成長率 × 相手のダメージ%)
              × 攻撃側の吹き飛ばし力補正 ÷ 相手の重量
```

この式と各種係数は `src/config/gameConfig.ts`（全体バランス）と
`src/characters/attacks.ts`（攻撃ごとの数値）に分離してあり、コードを変更せず
数値調整だけでバランス調整ができます。

## キャラクター

| キャラクター | タイプ | 特徴 |
| --- | --- | --- |
| **ジョリオ** | 万能型 | 赤い作業着の下水道の王。扱いやすく近中距離両対応。必殺技「マンホールギザー」で前方の敵を打ち上げる |
| **ビリネズ** | 高速型 | コンセントに住む黄色い電気生物。速いが軽く吹き飛びやすい。必殺技「ジグザグスパーク」で前方をしびれさせる |
| **ハヤスギ** | 突進型 | 高速移動用スーツの青い戦士。最高速は随一だが曲がりにくい上級者向け。必殺技「ハイパーダッシュモード」で一定時間移動・攻撃力が上昇（操作は不安定に） |
| **ダンボール・ジョー** | 罠・遠距離型 | 段ボール装甲の潜入兵士。接近戦は弱いがロケット花火と地雷トラップで戦う（同時設置数に上限あり） |

プレイヤーは既定でジョリオを操作し、残り3キャラクターはCPUが担当します
（性格：ビリネズ=攻撃的 / ハヤスギ=慎重 / ダンボール・ジョー=遠距離重視）。

キャラクターの数値（重量・移動速度・ジャンプ力・攻撃力・吹き飛ばし力・防御力・
必殺技性能）は `src/characters/characterData.ts` にデータとして分離されており、
新しいキャラクターを追加しやすい構造になっています。

## ステージ「ジョー・ジャンクション」

廃品置き場と工場を組み合わせた3Dアリーナ。中央の広い戦闘エリアの周囲に
コンテナ・鉄骨・ドラム缶・自動販売機・小型クレーン・パイプ・高低差のある
足場を配置しています。木箱・ドラム缶・壁・看板・自動販売機は攻撃や
吹き飛ばされたキャラクターの衝突で破壊可能で、ドラム缶は強い攻撃を受けると
爆発して周囲を巻き込みます。破片・パーティクル数には上限があります。

## CPU AI

- 3体のCPUはそれぞれ異なる性格パラメータ（攻撃的 / 慎重 / 遠距離重視）を持ち、
  同じ行動を取り続けないようになっています
- プレイヤーだけでなく、近い敵やダメージの高い敵を状況に応じて狙います
- 攻撃の回避・ガード、ステージ端からの回避、落下時の復帰、障害物の回避を行います
- 判断は毎フレームではなく一定間隔で更新し、処理負荷を抑えています
- 難易度 Easy / Normal / Hard をポーズメニューから変更可能（既定はNormal）

## パフォーマンス設定

ポーズメニューから画質 Low / Medium / High を選択できます（スマートフォンでは
自動的に Medium が初期選択されます）。ピクセル比の上限、影の有無、パーティクル数・
破片数の上限、描画距離が画質ごとに調整され、タブが非表示の間は描画・更新を停止します。

## デバッグ方法

**F3** キーでデバッグ表示のON/OFFを切り替えられます。表示内容:

- FPS、シーン内オブジェクト数、パーティクル数、設置中の地雷数
- 各キャラクターの座標・速度・ダメージ%・現在の状態
- CPUキャラクターが現在ターゲットにしている相手のID

本番プレイ時は初期状態で非表示です。

## 既知の制限事項（MVPスコープ）

- ステージは1種類、キャラクターは4種類のみ
- 高低差プラットフォームは簡易衝突判定のため、側面からは視覚的にすり抜けて
  見える場合があります（縦方向の乗り降りは正しく機能します）
- ステージ端の自動崖つかまりは未実装（二段ジャンプ・空中回避のみで復帰）
- キャラクター選択画面はなく、プレイヤーは常にジョリオ固定
- 破壊済みオブジェクトは「最初から」でのみ復元されます（試合中の自然復活なし）
- サウンドは簡易的な生成音のみ（BGMなし）
